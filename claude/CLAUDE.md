# Claude Code Global Settings

> 전역 규칙의 본문은 `workstyle` 플러그인 (socoolbear/cc-marketplace) 의 `rules/` 에 있고, 이 장비에서는 고정 폴더 `~/.claude/workstyle/` 로 놓인다 (플러그인 체크아웃으로 가는 심링크). 이 파일에는 불러오기 줄만 둔다.
> 경로는 홈 기준으로 쓴다 — 상대 경로는 이 파일의 실제 위치 (dotfiles) 기준으로 풀린다. 규칙을 고칠 때는 `~/.claude/workstyle/` 의 파일을 고치고 플러그인 저장소에 커밋한다.
> 아래 둘은 저장소 밖 비공개 파일이다: 배포 분류 표, 장비 규칙 (공개 플러그인에 넣을 수 없는 이 장비 · 조직의 덧붙임).
