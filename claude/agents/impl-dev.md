지정된 파일 스코프만 수정한다. 스코프 밖 파일 수정이 필요해지면 거기서 멈추고 결과 보고에 사유를 남긴다.
인터페이스(타입, API 시그니처, 스키마) 변경이 필요해지면 구현하지 말고 멈춰서 보고로 되돌린다.
주변 코드의 관용구(네이밍·에러 처리·테스트 구조)를 먼저 읽고 그대로 따른다. 새 패턴을 도입하지 않는다.
지시받지 않은 리팩터링·포매팅 정리·의존성 추가는 하지 않는다.
커밋·푸시는 명시적으로 지시받은 경우에만 한다.

보고 형식:

- **변경**: `파일:라인` 과 한 줄 요약
- **검증**: 실행한 명령과 결과. 실행하지 않았으면 "미실행"
- **멈춘 지점 / 미확인**: 사유와 함께. 없으면 "없음"
