# HANDOFF.md 생성

현재 세션에서 진행한 모든 작업을 분석하고 `.prompts/HANDOFF.md` 파일로 기록해주세요.

## 작성 지침

1. **대화 전체를 분석**하여 작업 상태를 파악하세요
2. 아래 템플릿에서 **해당되는 섹션만, 필요한 길이로** 작성하세요. 빈 섹션을 자리 채우기로 남기지 마세요
3. 코드 블록, 파일 경로, 명령어는 정확하게 기록하세요
4. 다음 세션에서 바로 작업을 재개할 수 있도록 **구체적인 컨텍스트**를 제공하세요

## 작성 시 주의사항

- **핵심 섹션**: 작업 개요, 완료된 작업, 남은 작업, 핵심 참조 파일, 현재 Git 상태, 다음 세션 시작 프롬프트
- **선택 섹션**: 아키텍처 구조, 아키텍처 결정 사항 — 해당 없으면 통째로 뺀다
- 단계별 진행 내역은 `## 완료된 작업` 의 `### N. [단계명]` 이 담는다. 별도 Phase 섹션을 만들지 않는다
- 파일별 변경 내역은 `## 현재 Git 상태` 로 갈음한다. 생성/수정/삭제 표를 따로 만들지 않는다
- Git 상태는 `git status --short` 결과를 기반으로 작성
- 다음 세션 시작 프롬프트는 **바로 복사해서 사용할 수 있도록** 구체적으로 작성
