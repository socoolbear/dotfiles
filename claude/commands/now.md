# 진행 상황 보고 후 이어가기

"진행 상황 알려줘. 다음에 진행할 일들 리스트업 해줘" 를 대신하는 명령이다. 사용자는 다른 창에서 일하다 돌아왔고 이 세션의 최근 도구 호출을 보지 않았다.

## 1. 자료를 모은다 (묻지 않고 읽는다)

- 진행 문서 (`.prompts/PROGRESS-<세션 앞 8자>.md`), 태스크 `notes.md` 의 「질문 대기열」, 「결정 로그」
- 자식 세션·팀메이트가 있으면 **메시지로 묻지 않고** 그 세션의 진행 문서와 `ListAgents` 상태를 읽어 합친다. 진행 문서가 없거나 30분 넘게 낡았을 때만 그 세션에 한 줄로 묻는다
- 돌고 있는 백그라운드 작업, 열려 있는 PR 의 CI·리뷰 상태 (이 세션이 올린 것만)

## 2. 아래 형식으로 보고한다

항목 이름과 순서를 바꾸지 않는다. 해당 사항이 없으면 `없음` 으로 쓴다. 항목마다 3줄을 넘기지 않고, 이 세션에서 지어낸 이름·약어는 풀어 쓴다.

```
**지금**: 전체 단계 중 어디인지 한 줄
**끝난 것**: 지난 보고 뒤에 끝난 것 (PR·커밋은 링크·해시)
**기다리는 것**: 무엇을, 누가·무엇이 끝나야 하는지 (자식 세션·빌드·리뷰·시각)
**사용자 몫**: 꼭 묻는 목록에 든 것만 `[분류] 할 것 — 추천안` 으로. 직접 할 수 있는 QA·조사·제안 결정은 여기 적지 않고 [바로] 로 보낸다
**다음**: 번호 목록. 앞에 [바로] (내가 이어서 할 것) 또는 [대기] (위 항목이 풀려야 할 것)
**스스로 정한 것**: 지난 보고 뒤의 [위임] 결정 한 줄씩 (뒤집으려면 말씀해 달라는 한마디)
```

## 3. 이어서 진행한다

- `[바로]` 항목이 있으면 보고를 쓴 같은 턴에서 첫 항목부터 **전부** 진행한다. "진행할까요?" 로 끝내지 않는다. 턴을 끝낼 때 꼬리표 「다음」 에는 `[대기]` 나 `없음` 만 남는다 (`[바로]` 가 남으면 멈춤 점검 훅이 막는다)
- 세션이 멈춰 있었다면 (오류·compact·자식 세션 응답 없음) 원인을 한 줄 적고 재개한다
- `[바로]` 항목이 없으면 「사용자 몫」 이 무엇인지로 끝낸다
- 인자가 `report` 면 보고만 하고 멈춘다

「꼭 묻는 목록」 기준은 `~/.claude/docs/workflow.md` §7 이다. 보고를 마치면 진행 문서의 「다음 단계」 를 이 보고와 맞춘다.
