# 아침 요약 지시 (claude-loop brief)

표준 입력으로 받은 자료 (야간 로그 · 세션별 「야간 결과」 · `[loop]` 커밋 · 내 열린 PR 상태 · 태스크별 「질문 대기열」 · 상황판 · 질문 지표 · 멈춤 점검 기록) 만으로
사용자가 출근해서 3분 안에 읽을 아침 보고를 한국어 존댓말 (해요체) 로 쓴다. 도구는 쓰지 않는다.

순서:

1. **결론 한 줄** — 밤사이 무엇이 진행됐고 사람이 볼 것이 몇 건인지
2. **사람이 결정할 것** — 질문 대기열, 확인창에 멈춘 동작, 상황판에서 「사용자 몫」 이 있는 세션을 태스크별로. 항목마다 추천안을 붙인다
3. **밤에 push 된 변경** — 세션별 `[loop]` 커밋 (repo · 브랜치 · 해시 · 한 줄 요약 · 바뀐 파일 수). 리뷰가 필요한 것을 먼저
4. **PR 상태** — CI 실패 · 리뷰 대기 · 승인됨으로 묶고, 야간 세션이 맡지 않은 PR 은 따로 표시
5. **건너뛴 세션** — 이유 (busy · 입력 중 · 검증 명령 미승인 등) 와 할 일 (`claude-loop approve <세션>` 등)
6. **개입 지표** — 어제 질문 창 수 (실행 승인 · 반복) · 글 질문 수 · 사람 입력 수 (승인 · 상태 묻기) · 중단
7. **멈춤 점검** — 끝난 턴 · 글 질문 · 꼬리표 · 사용자 몫 (분류 없어 막힌 것) 건수. 글 질문 표본 중 물을 만했던 것 (운영 · 되돌릴 수 없는 것 · 남에게 나가는 글 · 사용자의 몸이 필요한 일 · 구조적 결정 · 선례 없는 정책 결정 · 한도·예외) 의 비율을 오탐률로 적는다. 모드가 record 이고 기록이 3일 넘게 쌓였는데 오탐률이 10% 아래면 차단 모드 전환 명령 (`echo block > ~/.local/state/claude-loop/stop-gate/mode`) 을 안내한다

자료에 없는 것은 추측하지 않고 "자료 없음" 으로 쓴다. 링크가 있으면 그대로 붙인다.
