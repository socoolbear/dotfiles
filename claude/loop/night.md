# 야간 루프 지시 (claude-loop night 가 태스크 세션에 맡기는 일)

이 지시는 사용자 입력이 아니라 사용자가 미리 걸어 둔 예약 작업이다. 사람은 아침까지 없다.
이 세션의 진행 문서·태스크 `notes.md`·결정 로그를 먼저 읽고, 아래 순서로 한 바퀴만 진행한다.

## 할 일

1. **이 태스크의 내 열린 PR 돌보기** — 리뷰 지적·CI 실패·충돌을 고쳐 **그 PR 의 브랜치에만** push 한다.
   - 사람이 판단할 리뷰 지적 (설계 반론·범위 질문) 은 고치지 않고 「질문 대기열」 에 남긴다. PR 에 답글을 달지 않는다
2. **진행 문서의 다음 항목** 중 사용자 결정이 필요 없는 것을 진행한다. 결정이 필요한 항목은 건너뛰고 대기열에 남긴다
3. 끝나면 진행 문서에 「야간 결과」 절을 쓴다 (한 것 · 커밋 해시 · 검증 결과 · 멈춘 곳과 이유)

## 하지 않는 것 (이 지시가 CLAUDE.md 의 "직접 머지" 같은 규칙보다 우선한다)

- 머지 · dev/운영 배포 · workflow 실행 · 라벨 · PR/이슈 댓글·리뷰 · Slack·메일 등 외부 발송 · DB 쓰기
- `.github/`·`CLAUDE.md`·`AGENTS.md`·`.claude/`·dotfiles 수정
- 팀메이트 · 자식 세션 · 새 tmux window 띄우기 — 야간 가드가 따라가지 않는다. 나눠야 하면 이름 없는 서브에이전트 (`Agent`) 만 쓴다
- 사용자에게 질문 (`AskUserQuestion`) — 대신 태스크 `notes.md` 의 「질문 대기열」 에 `질문 / 추천안 / 근거 / 상태: 대기` 로 남긴다
- 커밋 서명·SSH 인증이 실패하면 서명을 끄거나 인증 방식을 바꾸지 않는다. 커밋하지 않은 채 「야간 결과」 에 적고 멈춘다
- 확인창 (야간 가드) 에 막힌 동작을 다른 방법으로 돌아가지 않는다. 막힌 것 자체를 「야간 결과」 에 적는다

## 커밋

- 메시지는 `[loop] ` 로 시작한다 (아침에 사람이 골라 본다)
- 검증 명령이 정해져 있으면 끝내기 전에 통과해야 한다 (검증 게이트가 막는다). 테스트를 지우거나 고쳐서 통과시키지 않는다
